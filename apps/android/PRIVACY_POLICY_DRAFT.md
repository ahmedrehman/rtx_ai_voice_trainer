# AI Voice Trainer Privacy Policy Draft

AI Voice Trainer uses microphone access so users can practice speaking and receive feedback.

The Android app sends typed text, selected practice settings, and microphone audio samples to the AI Voice Trainer backend when the user uses the trainer or debug features. The backend processes these requests to provide chat, correction, realtime voice, and audio roundtrip testing.

The Android app does not contain an OpenAI API key. Provider keys remain on the server.

The Android app does not include advertising SDKs or third-party analytics SDKs.

Users can deny microphone permission. Voice practice features require microphone permission, while typed chat can still work when supported by the backend.

This draft should be reviewed and hosted at a public URL before Play Store submission.

# AI Voice Trainer Privacy Policy

Last updated: June 12, 2026

AI Voice Trainer helps users practice speaking and receive language feedback.

## Information The App Uses

The Android app may send typed text, selected practice settings, and microphone audio samples to the AI Voice Trainer backend when the user uses trainer or debug features.

The backend processes this information to provide chat, correction, realtime voice, and audio roundtrip testing.

## Microphone

AI Voice Trainer requests microphone permission for speech practice.

Users can deny microphone permission. Voice practice features require microphone permission, while typed chat can still work when supported by the backend.

## API Keys

The Android app does not contain an OpenAI API key or other provider API keys. Provider keys remain on the server.

## Advertising And Analytics

The Android app does not include advertising SDKs.

The Android app does not include third-party analytics SDKs.

## Contact

For privacy questions, contact the app developer through the Google Play listing.
